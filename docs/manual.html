official manual

Your HTML, in a real browser.

Fenestra opens the port on 127.0.0.1 and hands the site to your browser. It is not a browser — it is the window between your folder and the browser you already use.

Windows · Linux · macOSno cloudno account

How it works

Three steps, no configuration.

1

You open the HTML

Double-click a .html or a build folder.

2

Fenestra serves it

A local server starts on 127.0.0.1, with a stable port per folder.

3

The browser shows it

The page opens in the browser you pick below.

one essential step

Make Fenestra the default for .html

Every system has its own way. Pick yours:

This step is optional. To open a project once, drag its index.html onto Fenestra or pass the path; the .html handler stays unchanged.

Windows

Through Windows Settings:

  1. Open Settings (Win + I).
  2. Go to Apps → Default apps.
  3. Search .html and choose Fenestra.

Shortcut: ms-settings:defaultapps.

Create a shortcut for a site

A shortcut is not just a link to the .html: it must start Fenestra with the file as an argument.

Windows

  1. Right-click the Desktop → New → Shortcut.
  2. In “Type the location of the item”, paste:
    %LOCALAPPDATA%\Fenestra\Fenestra.exe "%USERPROFILE%\Documents\Example\dist\index.html"
  3. Click Next, name it Example, and finish.
  4. Optional: Properties → Start in = the dist folder.
  5. Double-click it to test.

Windows expands %LOCALAPPDATA% and %USERPROFILE%. Keep the quotes around the .html path.

Example Properties
GeneralShortcutDetails

Start inC:\...\dist
RunNormal window
OK

Linux

Create ~/.local/share/applications/example.desktop:

[Desktop Entry] Type=Application Name=Example Exec=/home/you/.local/bin/fenestra "/home/you/Example/dist/index.html"

Mark it trusted or run update-desktop-database. Linux does not expand $HOME in .desktop files — use an absolute path or a wrapper script.

example.desktop — Text Editor
[Desktop Entry]
Type=Application
Name=Example
Exec=/home/you/.local/bin/fenestra "/home/you/Example/dist/index.html"

macOS

Save Example.command:

#!/bin/sh exec "$HOME/Applications/fenestra" \ "$HOME/Example/dist/index.html"

Run chmod +x Example.command once, then double-click it.

Example.command
#!/bin/sh
exec "$HOME/Applications/fenestra" \
  "$HOME/Example/dist/index.html"
$ chmod +x Example.command

Everything in one folder: %LOCALAPPDATA%\Fenestra.

Crea una scorciatoia per un sito

Una scorciatoia non è solo un collegamento all'.html: deve avviare Fenestra con il file come argomento.

Windows

  1. Fai clic destro sul desktop → Nuovo → Collegamento.
  2. In “Digita il percorso dell'elemento”, incolla:
    %LOCALAPPDATA%\Fenestra\Fenestra.exe "%USERPROFILE%\Documents\Example\dist\index.html"
  3. Fai clic su Avanti, chiamala Example e completa.
  4. Facoltativo: Proprietà → Esegui in = la cartella dist.
  5. Fai doppio clic per provarla.

Windows espande %LOCALAPPDATA% e %USERPROFILE%. Mantieni le virgolette attorno al percorso dell'.html.

Linux

Crea ~/.local/share/applications/example.desktop:

[Desktop Entry] Type=Application Name=Example Exec=/home/you/.local/bin/fenestra "/home/you/Example/dist/index.html"

Rendilo attendibile o esegui update-desktop-database. Linux non espande $HOME nei file .desktop — usa un percorso assoluto o uno script wrapper.

macOS

Salva Example.command:

#!/bin/sh exec "$HOME/Applications/fenestra" \ "$HOME/Example/dist/index.html"

Esegui chmod +x Example.command una volta, poi fai doppio clic.

Example.command
#!/bin/sh
exec "$HOME/Applications/fenestra" \
  "$HOME/Example/dist/index.html"
$ chmod +x Example.command

officiële handleiding

Je HTML, in een echte browser.

Fenestra opent de poort op 127.0.0.1 en geeft de site aan je browser. Het is geen browser — het is het venster tussen je map en de browser die je al gebruikt.

Windows · Linux · macOSgeen cloudgeen account

Hoe het werkt

Drie stappen, geen configuratie.

1

Je opent de HTML

Dubbelklik op een .html of een buildmap.

2

Fenestra serveert het

Een lokale server start op 127.0.0.1, met een vaste poort per map.

3

De browser toont het

De pagina opent in de browser die je hieronder kiest.

één essentiële stap

Maak Fenestra de standaard voor .html

Elk systeem heeft zijn eigen aanpak. Kies de jouwe:

Deze stap is optioneel. Om een project één keer te openen, sleep je de index.html naar Fenestra of geef je het pad mee; de .html-koppeling blijft ongewijzigd.

Windows

Via de Instellingen van Windows:

  1. Open Instellingen (Win + I).
  2. Ga naar Apps → Standaard-apps.
  3. Zoek .html en kies Fenestra.

Snelkoppeling: ms-settings:defaultapps.

Linux

Registreer de handler één keer:

  1. fenestra --install
  2. xdg-mime default fenestra.desktop text/html

Ongedaan maken met fenestra --uninstall.

Terminal
user@linux:~$ xdg-mime default fenestra.desktop text/html

Maak een snelkoppeling voor een site

Een snelkoppeling is niet zomaar een link naar de .html: hij moet Fenestra starten met het bestand als argument.

Windows

  1. Rechtsklik op het bureaublad → Nieuw → Snelkoppeling.
  2. Plak bij “Typ de locatie van het item” het volgende:
    %LOCALAPPDATA%\Fenestra\Fenestra.exe "%USERPROFILE%\Documents\Example\dist\index.html"
  3. Klik op Volgende, noem het Example en rond af.
  4. Optioneel: Eigenschappen → Uitvoeren in = de map dist.
  5. Dubbelklik erop om te testen.

Windows vult %LOCALAPPDATA% en %USERPROFILE% in. Houd de aanhalingstekens rond het pad naar de .html.

Maak ~/.local/share/applications/example.desktop aan:
