Fenestra manual
official manual

Your HTML, in a real browser.

Fenestra opens the port on 127.0.0.1 and hands the site to your browser. It is not a browser — it is the window between your folder and the browser you already use.

Windows · Linux · macOSno cloudno account

How it works

Three steps, no configuration.

1

You open the HTML

Double-click a .html or a build folder.

2

Fenestra serves it

A local server starts on 127.0.0.1, with a stable port per folder.

3

The browser shows it

The page opens in the browser you pick below.

one essential step

Make Fenestra the default for .html

Every system has its own way. Pick yours:

Windows

Through Windows Settings:

  1. Open Settings (Win + I).
  2. Go to Apps → Default apps.
  3. Search .html and choose Fenestra.

Shortcut: ms-settings:defaultapps.

Linux

Register the handler once:

  1. fenestra --install
  2. xdg-mime default fenestra.desktop text/html

Undo with fenestra --uninstall.

macOS

No terminal needed — use Finder:

  1. Right-click an .html → Get Info.
  2. Open with → Fenestra.
  3. Click Change All….

Every day

The commands that matter.

Fenestra.exe "C:\project\dist\index.html" Fenestra.exe "C:\project\dist" Fenestra.exe --port 8080 "C:\project\dist"
Double-click Fenestra.exe with no file to open the settings screen. --diagnose shows which browser Windows is handing over.

Create a shortcut for a site

A shortcut is not just a link to the .html: it must start Fenestra with the file as an argument. Each system does it its own way.

Windows

  1. Right-click the Desktop → New → Shortcut.
  2. Paste the full command as the location (below).
  3. Name it Example and finish.
Example Properties
GeneralShortcutDetails
Target"...\Fenestra.exe" "C:\...\dist\index.html"
Start inC:\...\dist
RunNormal window
OK

The quotes are required. “Start in” is optional.

Linux

Create ~/.local/share/applications/example.desktop:

example.desktop — Text Editor
[Desktop Entry]
Type=Application
Name=Example
Exec=/home/you/.local/bin/fenestra "/home/you/Example/dist/index.html"

Then mark it trusted or run update-desktop-database.

macOS

Save Example.command:

Example.command
#!/bin/sh
exec "$HOME/Applications/fenestra" \
  "$HOME/Example/dist/index.html"
$ chmod +x Example.command

Run chmod +x Example.command once.

Where things live

Everything in one folder: %LOCALAPPDATA%\Fenestra.

Sem terminal — pelo Finder:

  1. Botão direito no .html → Obter informações.

Crie um atalho para um site

Atalho não é só um link para o .html: ele precisa iniciar o Fenestra com o arquivo como argumento. Cada sistema faz do seu jeito.

Windows

  1. Botão direito na Área de Trabalho → Novo → Atalho.
  2. Cole o comando completo como local (abaixo).
  3. Dê o nome Exemplo e conclua.
Propriedades de Exemplo
GeralAtalhoDetalhes
Destino"...\Fenestra.exe" "C:\...\dist\index.html"
Executar emC:\...\dist
ExecutarJanela normal
OK

As aspas são obrigatórias. “Executar em” é opcional.

Linux

Crie ~/.local/share/applications/exemplo.desktop:

exemplo.desktop — Text Editor
[Desktop Entry]
Type=Application
Name=Exemplo
Exec=/home/voce/.local/bin/fenestra "/home/voce/Exemplo/dist/index.html"

Marque como confiável ou rode update-desktop-database.

macOS

Salve Exemplo.command:

Exemplo.command
#!/bin/sh
exec "$HOME/Applications/fenestra" \
  "$HOME/Exemplo/dist/index.html"
$ chmod +x Exemplo.command

Rode chmod +x Exemplo.command uma vez.
