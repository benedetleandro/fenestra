Fenestra manual
official manual

Your HTML, in a real browser.

Fenestra opens the port on 127.0.0.1 and hands the site to your browser. It is not a browser — it is the window between your folder and the browser you already use.

Windows · Linux · macOSno cloudno account

How it works

Three steps, no configuration.

1

You open the HTML

Double-click a .html or a build folder.

2

Fenestra serves it

A local server starts on 127.0.0.1, with a stable port per folder.

3

The browser shows it

The page opens in the browser you pick below.

Choose Fenestra's browser

These are the browsers Fenestra supports. In the installed app, click one to pin it — the choice applies to the next .html.

Microsoft Edge→Google Chrome→CChromium→Mozilla Firefox→Brave→Vivaldi→Opera→

↻ Refresh list

Make Fenestra the default: a web page cannot change Windows associations. Click Set as default to open the Windows dialog, then pick Fenestra and check "Always use this app".

Linux: xdg-mime default fenestra.desktop text/html.
macOS: Finder > right-click the .html > Get Info > Open with > Fenestra > Change All.

Every day

The commands that matter.

Fenestra.exe "C:\project\dist\index.html" Fenestra.exe "C:\project\dist" Fenestra.exe --port 8080 "C:\project\dist"
Double-click Fenestra.exe with no file to open the settings screen. --diagnose shows which browser Windows is handing over.

Where things live

Everything in one folder: %LOCALAPPDATA%\Fenestra.

Fenestra.exe manual.html settings.json (only when you pin a browser)
manual oficial

Seu HTML, no navegador de verdade.

O Fenestra abre a porta em 127.0.0.1 e entrega o site para o seu navegador. Ele não é um navegador — é a janela entre a sua pasta e o navegador que você já usa.

Como funciona

Três passos, sem configuração.

1

Você abre o HTML

Duplo clique em um .html ou em uma pasta de build.

2

O Fenestra serve

Um servidor local sobe em 127.0.0.1, com porta estável por pasta.

3

O navegador mostra

A página abre no navegador que você escolher aqui embaixo.

Escolha o navegador do Fenestra

Estes são os navegadores que o Fenestra suporta. No app instalado, clique em um para fixar a escolha — vale no próximo .html.

Microsoft Edge→Google Chrome→CChromium→Mozilla Firefox→Brave→Vivaldi→Opera→

↻ Atualizar lista

Torne o Fenestra o padrão: uma página web não pode mudar associações do Windows. Clique em Tornar padrão para abrir o diálogo do Windows, escolha Fenestra e marque "Sempre usar este aplicativo".

Linux: xdg-mime default fenestra.desktop text/html.
macOS: Finder > botão direito no .html > Obter informações > Abrir com > Fenestra > Alterar tudo.
